# Site web Ecole 241 #

## Description ##
Le présent projet a pour but d'apprendre à transformer une maquette ou une idée en une interface web moderne, organisée et responsive.
Pour ce travail nous allons réaliser le site web de l'école 241, à partir d'une maquette.

## Les technologies utilisées ##
- HTML, 
- SCSS, 
- JS
- vite JS
- pnpm
- Git, Github

## Les instructions de lancement ##
### Serveur locale ###
*** pnpm run dev ***

### Build ###
*** pnpm build ###
